# 支付部署维护说明

上游为 v03413/BEpusdt，本分支已合并 d36d34fe04725b5be121d2877f6251da9cc6089b。
fork 在上游基础上保留以下定制：

- 独立金额保留表，使用数据库唯一约束，订单过期、删除及程序重启均不释放金额。
- 仅回环地址可访问的健康检查，返回扫描进度及待付单数量，不返回凭据。
- 金额并发冲突、迟到付款、错误币种、少付及模板加载的回归验证。
- GitHub Actions 构建管理页面后嵌入二进制；构建和测试在云端执行。

全新网关可直接初始化金额表。已有历史交易的网关必须先回填历史金额，避免复用。
金额保留记录必须永久保存；恢复旧快照时不能丢失快照之后的保留记录。
测试通过不能替代真实链上付款验收。正式启用收款前需验证链上确认、签名通知、商城到账及发货。

服务器配置、实际钱包地址、邮件授权码和 API 密钥仅保留在部署服务器的受限目录，不能提交进仓库。
后续更新先比较上游变化、合并并运行回归，再核验工件来源和 SHA256；不在业务服务器编译。
